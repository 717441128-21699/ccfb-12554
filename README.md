# 大板连纹排版工具

大理石大板背景墙的连纹排版系统：导入大板正反面照片 → 自动提取纹路特征 → 在墙面/地面/台面展开图上自动连纹排版 → 校验接缝错位（≤3mm）与开孔避让 → 输出出材率和切割图。

技术栈：TypeScript（strict）+ Vite + WebGL2，无重型运行时依赖。

## 现场痛点对应

| 业务诉求 | 实现方式 |
| --- | --- |
| 正反面拍照导入、毫米尺寸、同荒料按切割顺序编号 | `src/state/importer.ts`，文件名约定 `荒料号_序号_宽x高.jpg`，也可手动录入 |
| 板可旋转、可书本式对开 | 8 种朝向（4 个 90° 旋转 × 水平镜像），几何变换在 `src/core/geometry.ts`，纹理 UV 变换在 GPU |
| 自动找接缝最顺的摆法 | beam search 求解器 `src/core/solver.ts`，按接缝纹路错位 + 角度连续性 + 同荒料相邻序号先验排序 |
| 接缝错开不超过 3mm | `src/core/seam.ts` 逐采样点评估，超差计入硬惩罚并在接缝明细标红 |
| 门洞窗洞插座躲开裂纹 | `src/core/constraints.ts` 折线-矩形精确距离，开口带安全避让边距，违规为硬约束 |
| 出材率、20 块板利用率 | `coverageArea()` 条带法算净覆盖/毛用板；右侧面板实时显示 |
| 切割图标每刀位置和先后 | `buildCutPlan()` 反推原板保留矩形，按车间“先长条后截头”生成有序刀路，画布橙色叠加 |
| 业主看铺好的整墙效果 | WebGL2 用真实照片纹理按最终摆法渲染 |
| 一面墙 10 秒内出方案 | 20 板实测 ~0.3–0.4s（见 `src/core/bench.test.ts`），10s 为求解超时预算 |

## 目录结构

```
src/
  core/            纯逻辑，不依赖 DOM，全部可单测
    types.ts         领域模型与默认求解参数
    geometry.ts      8 朝向变换、边映射、碰撞与点线矩形距离
    seam.ts          边签名重采样与接缝对纹评分
    constraints.ts   裂纹避让、覆盖面积、出材率
    veinDetect.ts    照片像素分析：脊线/方向场/边签名/裂纹初判
    synthetic.ts     演示数据：参数化同荒料切片（纹路与签名严格同源）
    solver.ts        beam search 排版 + 切割图生成
  render/
    webglRenderer.ts WebGL2 渲染（纹理板、接缝、开口、裂纹、切割线）
  state/
    store.ts         响应式状态 + localStorage 持久化
    importer.ts      照片导入与检测管线
  ui/                三栏界面（板库 / 画布 / 工程面板）
```

## 操作流程

1. `npm run dev` 启动，浏览器打开提示地址（需支持 WebGL2 的 Chrome/Edge）。
2. 点「载入演示数据」快速体验：8 块同荒料板（含一条裂纹）、一个插座、一个窗洞。
3. 真实使用时点「导入大板照片」，按 `B1_0_1600x2400.jpg` 命名批量选择；检测到裂纹会提示人工复核。
4. 在右侧维护安装面尺寸和开口（位置/尺寸/避让距离）。
5. 点「自动连纹排版」，右侧看接缝逐缝明细、出材率、弃料面积；切到「切割图」看每一刀。

## 设计要点

- **边签名模型**：每条板边等间距采样纹路交点的法线深度与切线角度；接缝两侧同物理位置比较深度差，即视觉错位量。
- **采样对齐**：两侧签名强制等物理步长、同索引对齐，避免 180° 旋转后采样网格错位产生假性超差。
- **可填充性剪枝**：新板不得制造任何剩余板都填不进的窄缝，从根上杜绝旋转板切碎版面。
- **可复现**：求解随机数固定种子（mulberry32），同一输入方案一致，便于现场复核。
- **检测可人工修正**：裂纹是提示性初判结果，数据模型支持人工增删后重算避让。

## 当前边界与后续

- 求解器按矩形板、矩形安装面建模；异形板/弧形墙需扩展锚点策略。
- 真实照片的纹路检测基于结构张量脊线，强光反照照片建议重拍；签名质量决定对纹上限。
- 背面照片目前仅存档，未参与正反面匹配校验。
