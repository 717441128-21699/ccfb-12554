# 大板连纹排版系统（Slab Vein Layout）

面向大理石大板背景墙 / 地面 / 台面的连纹排版工具：板材入库 → 展开图建模 → 自动连纹排版 → 出材率核算 → 切割刀路 → 业主效果图。

技术栈：**TypeScript + Vite + 原生 WebGL2**（无第三方渲染库），全部数据本地存储，不上传服务器。

## 运行

```bash
npm install
npm run dev          # 开发，默认 http://127.0.0.1:5173
npm run build        # 类型检查 + 生产构建
npm run test:smoke   # Node 求解器冒烟测试（10 项断言，含裂纹避让/书本对开/板不足）
```

首次打开会自动生成 20 块演示大板（3 个荒料，同荒料纹路横向连续，3 块带裂纹）和 3 张展开图，可直接体验完整流程。

## 三个工作页

### ① 板材库（拍板师傅）
- 大板**正反面拍照导入**（背面照片与正面同名自动配对，详情页存档展示）
- 尺寸按毫米录入；同一荒料按**切割顺序编号**，相邻序号默认纹路相连
- 在板面上点击绘制裂纹折线，双击结束；裂纹参与后续硬约束避让
- 支持 4 种姿态预览：原样 / 水平镜像（书本对开）/ 180° / 垂直镜像，可叠加 90° 旋转

### ② 墙面 / 地面 / 台面（设计师）
- 展开图按毫米建模，支持门洞、窗洞、插座三类洞口，位置与尺寸可编辑
- 完全落在洞口内的网格自动跳过，跨洞口的格子保留并在板上开孔

### ③ 连纹排版（自动求解 + 多方视角）
- **顺纹连铺 / 书本对开**两种模式，可整面旋转 90°（板竖铺）
- 点击「生成最优排版方案」，束搜索（beam search）枚举 未用板 × 姿态 组合
- 每对接缝用板边纹路条带描述子 + 纹路穿越点做对齐评分，自动选出接缝两边接得最顺的摆法
- **接缝容忍 3mm 可调**，绿色合格 / 红色超差，逐缝标注实际错位毫米数
- **裂纹硬约束**：插座 20mm、门窗 10mm 安全边距内有裂纹的摆法直接淘汰；无可行解时放宽并显式告警
- 老板视角：出材率、用板数 / 批次总量、投板毛面积、实铺净面积、剩余板
- 切割图：每块板按刀序给出修边裁切与洞口开孔的局部坐标刀路
- 业主视角：关掉标注图层即为整墙效果图，可一键导出 PNG

## 关键算法口径

| 项 | 口径 |
|---|---|
| 接缝评分 | 板边 128 点亮度条带（百分位对比度拉伸，抗曝光差异）+ 强梯度穿越点配对，±40mm 范围搜索最佳纵向偏移 |
| 荒料偏好 | 同荒料相邻切割序号 −0.35、同荒料 −0.12、跨荒料 +0.25 |
| 出材率 | 实铺净面积（含洞口扣减）÷ 投板毛面积；板不足时缺口面积不计入产出 |
| 切割坐标 | 全部为板面局部毫米坐标，姿态逆变换生成，可直接交车间 |
| 性能 | 20 板 / 4×2 网格实测求解 < 50ms（特征提取约 300ms），远低于 10 秒要求 |

## 目录

```
src/
  types.ts      数据模型（单位统一毫米）
  geometry.ts   网格划分、姿态正/逆变换、折线-矩形相交
  vein.ts       板边纹路特征提取、姿态-边映射、接缝匹配
  solver.ts     束搜索求解器、裂纹约束、出材率、切割方案
  gl.ts         WebGL2 渲染器（纹理/相机/2D 叠加层）
  demo.ts       程序化连纹大理石演示数据
  views/        三个工作页
scripts/
  smoke.ts      Node 求解器测试
  cdp-test.mjs  浏览器端到端测试
```

## 已知边界

- 照片以 dataURL 存 localStorage，单批建议 ≤ 30 张；大批量后续可换 IndexedDB
- 自动网格按统一标准板尺寸划分，混尺板只做过滤不参与自动排版
- 纹路匹配基于 2D 照片边缘特征，立体凹凸面需现场复核
