# 商业照明配光预览 · Light Studio

面向商业照明销售/方案场景的浏览器端配光预览工具。导入灯具 **IES（IESNA LM-63）** 文件，在可定制的房间里布灯，实时查看工作面照度伪彩、阴影与眩光，一键导出 PDF 照度报告。

- 纯前端：TypeScript + Vite，渲染器为**手写 WebGL2**（无 Three.js 等 3D 框架）
- 照度计算在 **Web Worker** 中进行，主线程只负责交互与渲染
- 物理量单位：长度米、光强坎德拉（cd）、光通量流明（lm）、照度勒克斯（lx）

## 五个功能页

| 页面 | 能力 |
| --- | --- |
| 灯具库 | 上传/解析 IES、极坐标配光曲线、半光强角、积分通量、选用灯具 |
| 房间搭建 | 房间尺寸、工作面高度、地/墙/顶反射率、门窗洞口与玻璃透光率 |
| 布灯 | 视口点击放灯、矩形阵列、逐灯位置/朝向/调光编辑、拖动移动 |
| 渲染预览 | WebGL2 实体 + 阴影（每灯一张深度贴图）、工作面伪彩、实时指标 |
| 照度报告 | 俯视伪彩图（含等值线）、平均/最小/最大照度、均匀度、UGR、PDF 导出 |

## 计算方法

- **直射照度**：E = I(θ,φ)·cosθ / r²。I 由 IES 配光表双线性插值得到，按额定通量相对测试通量缩放；θ 为灯具向下轴与光线夹角，含距离平方反比与入射角余弦。
- **门窗遮挡**：线段与墙面求交，命中洞口按玻璃透光率折减（1−T），命中实墙直射为零。
- **一次间接反射**：把墙面/顶面离散为朗伯面片，先求各面片直射入射得到出射度 M=ρE，再以 dE = M·cosα·cosβ·A/(πr²) 叠加到工作面；另补「墙→顶→工作面」主路径。地面反射对水平工作面的一次反弹几何项为零，不参与。
- **眩光 UGR**：CIE 117 简化式 8·log₁₀(0.25/Lb · Σ Ls²/P²)，P 取 Guth 位置指数双线性插值表，观察者位于房间纵向 1/4 处、眼高 1.2 m。
- **均匀度**：U0 = 最小照度/平均照度（GB 50034 主指标），另给 U1 = 平均/最大。
- **伪彩色标**：默认取 95 分位照度作上限，避免被局部峰值压扁整体色阶；也可手动指定。

## 手算核对（npm run verify）

`tests/verify.ts` 用独立的手算公式逐项核对引擎，全部通过：

- 配光表球面积分通量 = 额定通量
- 正下方 / 偏移点直射照度：与 E=I·cosθ/r² 手算一致
- 距离加倍轴向照度按 1/r² 衰减（比例 4.000）
- 网格引擎直射分量 = 单灯线性叠加（网格离散误差 < 5%）
- 窗洞折减系数 = 1−T
- 全黑房间间接照度为 0；有反射率时间接贡献为正且量级合理
- 同总通量下分散布灯 UGR 低于集中单灯
- 调光系数线性生效

性能：20 盏灯、32×32 网格（含一次反射）在 Worker 中计算约 30–170 ms，满足拖拽实时更新。

## 说明与边界

- 灯具按竖直向下安装建模（商业吸顶/嵌入/导轨常规姿态），yaw 仅旋转非轴对称配光的水平朝向。
- 间接反射为一次反弹（含墙→顶主路径）的工程近似，适用于方案阶段预览，不替代 Dialux/AGi32 等正式照明设计软件的完整光传遞计算。
- 阴影为每盏灯一张 512px 正交深度贴图（2D 纹理数组），上限 24 盏。
- PDF 中文通过 Canvas 渲染为图片嵌入，不依赖额外字体文件。
